  1. Install the two free tools — one click each: Node.js from nodejs.org and Ollama from ollama.com.
  2. Grab this project's server folder (the one with package.json). On Windows just double-click run-nova-ai.bat — it installs everything and starts the server at localhost:3000. Otherwise, in a terminal inside that folder run npm install, then npm start.
  3. Pull the small AI model once (about 500 MB): ollama pull qwen3:0.6b
  4. Done. The chip up top turns green within ~15 seconds and commands auto-switch to AI. No server? Everything already works offline with the built-in commands.
